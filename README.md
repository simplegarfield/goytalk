# Prosta Aplikacja Czatowa (Node.js + Socket.io)

Aplikacja umożliwia prowadzenie rozmów na żywo w czasie rzeczywistym z systemem unikalnych nicków (sprawdzanie po stronie serwera, dzięki czemu nikt nie zajmie nicku kogoś innego).

## Wymagania
Node.js zainstalowany na komputerze (pobierz ze strony nodejs.org).

## Uruchomienie:
1. Rozpakuj archiwum ZIP.
2. Otwórz terminal w folderze projektu.
3. Wpisz:
   ```bash
   npm install
   ```
4. Uruchom serwer:
   ```bash
   npm start
   ```
5. Otwórz w przeglądarce: `http://localhost:3000`
